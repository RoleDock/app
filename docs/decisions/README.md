# Architecture Decision Records

Create an Architecture Decision Record (ADR) only when:

- the decision has meaningful long-term consequences;
- multiple reasonable alternatives existed;
- future contributors would reasonably ask why the choice was made.

Do not create ADRs for trivial implementation details.

## Naming

Use a sequential number followed by a short decision title:

```text
0001-short-decision-title.md
```

## Suggested structure

1. Context
2. Decision
3. Alternatives considered
4. Consequences

No ADR has been created yet. Add one only when a concrete project decision meets
the criteria above.
