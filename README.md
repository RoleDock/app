# RoleDock

Analyze. Apply. Track.

RoleDock is a job application workspace designed to help candidates:

- analyze job offers against their profile;
- identify relevant CV keywords;
- generate application messages and cover letters;
- track applications;
- quickly retrieve context during recruiter calls.

## Status

Early development — MVP v0.1.

## Applications

- `backend/` — Spring Boot REST API
- `web/` — Angular web application
